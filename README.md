# Maoye Panel Simulator · 燕云面板模拟器

脱胎于《燕云培养助手》的独立小工具：**在装备板块配置词条，战斗属性面板实时联动**。

只做一件事：把「流派 + 心法 + 套装 + 装备词条」折算成战斗属性面板，不涉及伤害计算与毕业度评价。

## 界面布局

**PC（≥1024px）：三栏**
```
┌──────────────┬──────────────┬────────────────────────┐
│  战斗属性面板  │  流派与心法   │      装备配置          │
│  常驻左侧      │  流派/变体    │  部位标签页 + 槽位卡片  │
│  （实时联动）  │  心法(≤4)     │  点槽位弹出词条选择层   │
│              │  套装选择     │  宫/商/角/徵/羽/定音    │
└──────────────┴──────────────┴────────────────────────┘
```

**移动端（<1024px）：底部标签栏**
- 三个视图：面板 / 配置 / 装备
- 装备词条选择为**底部弹出面板（Bottom Sheet）**，大点击区域

## 交互要点

- **词条选择**：点击槽位卡片，弹出该槽位可选词条列表（带满值预览、搜索、清空）。
- **数值**：选中词条后默认填满值，可手动微调（限制在值域内）。
- **互斥**：同部位商/角/徵/羽四槽词条互不重复，已占用的词条在选择层中置灰。
- **部位进度**：部位标签上的角标显示该部位已填槽位数。

## 快速开始

```bash
npm install
npm run dev        # 开发预览 http://localhost:3100
npm run build      # 构建到 dist/
```

部署到子路径（如挂到 maoye.world 下）：

```bash
BASE_PATH=/panel/ npm run build
```

## 计算链路

```
基础面板
 + 武库（本系属攻）
 + 心法
 + 套装
 + 装备词条
 + 五维 → 攻/会心/会意/气血/防御
 + 无相吸收（无相攻击/穿透 → 本系）
 + 武学天赋（含五维需求 / 属性需求折算）
 = 原始总和 → 判定有效值（精准/会心/会意）
 → 增益有效值（神力/定音增伤 ÷ (1+增益抗性)）
```

## 数值口径约定

- **内部计算**：所有百分比以「百分数点数」存储（会心 16.2 表示 16.2%）。
- **词条数据**：百分比词条以「小数」存储（0.162 表示 16.2%），在计入面板时统一 ×100。
- **显示**：攻击/五维取整，百分比保留 1 位小数，穿透保留 1 位小数。

## 维护说明

- 数值更新只需改 `src/data/` 下的数据文件，`domain/panel.js` 无需改动。
- 词条池用「积木」组合表达（见 `affinities.js` 的 `积木` / `本系属攻`），避免逐部位罗列。
- 定音词条分两类：武器/首饰为通用穿透库；防具为流派变体专属招式增伤库。
