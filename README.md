# Maoye Panel Simulator · 燕云面板模拟器

脱胎于《燕云培养助手》的独立小工具：**在装备板块配置词条，战斗属性面板实时联动**。

只做一件事：把「流派 + 心法 + 套装 + 装备词条」折算成战斗属性面板，不涉及伤害计算与毕业度评价。

## 界面布局

```
┌──────────────┬──────────────┬────────────────────────┐
│  战斗属性面板  │  流派与心法   │      装备配置          │
│  （实时联动）  │  流派/变体    │  8 部位 × 6 槽位       │
│              │  心法(≤4)     │  宫/商/角/徵/羽/定音    │
│              │  套装选择     │  词条 + 数值可调        │
└──────────────┴──────────────┴────────────────────────┘
```

## 快速开始

```bash
npm install
npm run dev        # 开发预览 http://localhost:3100
npm run build      # 构建到 dist/
```

部署到子路径（如挂到 maoye.world 下）：

```bash
BASE_PATH=/panel/ npm run build
```

## 计算链路

```
基础面板
 + 武库（本系属攻）
 + 心法
 + 套装
 + 装备词条
 + 五维 → 攻/会心/会意/气血/防御
 + 无相吸收（无相攻击/穿透 → 本系）
 + 武学天赋（含五维需求 / 属性需求折算）
 = 原始总和 → 判定有效值（精准/会心/会意）
```

## 数值口径约定

- **内部计算**：所有百分比以「百分数点数」存储（会心 16.2 表示 16.2%）。
- **词条数据**：百分比词条以「小数」存储（0.162 表示 16.2%），在计入面板时统一 ×100。
- **显示**：攻击/五维取整，百分比保留 1 位小数，穿透保留 1 位小数。

## 维护说明

- 数值更新只需改 `src/data/` 下的数据文件，`domain/panel.js` 无需改动。
- 词条池用「积木」组合表达（见 `affinities.js` 的 `积木` / `本系属攻`），避免逐部位罗列。
- 定音词条分两类：武器/首饰为通用穿透库；防具为流派变体专属招式增伤库。
